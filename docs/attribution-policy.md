# Attribution policy — Verifier and the Innotel platform portfolio

Applies to every repository in the [Innotel platform
stack](https://github.com/innotelinc/innotel-platform-stack); this document is
the readable form of the policy that `.githooks/guard-lib` enforces
mechanically.

## The rule

**No one but Darnel Hunter <dhunter@innotel.us> may ever be credited.**
Commit messages, PR titles and descriptions, and every line added to any file
must contain attribution for nobody else.

## What the guard rejects

1. **Git trailers naming anyone else.** `Co-Authored-By:`, `Signed-off-by:`,
   `Authored-By:`, `Reviewed-By:`, and the other standard credit trailers must
   either be absent or name one of the owner's identities. GitHub's
   `dependabot[bot]` is the single allowed exception — its automated commits
   carry a `Signed-off-by`.
2. **Attribution phrases crediting an AI assistant or tool.** Lines like
   "Generated with X", "Co-authored-by: X", "Built by X", "Credits: X" where X
   is an AI tool are rejected wherever they appear — commit messages, PR text,
   and file content alike.

## What passes

- Plain product prose that merely names a technology: an "OpenAI-compatible
  endpoint", "generated by the release pipeline", "compatible with Claude
  Desktop configurations" — these describe the product, they credit no one.
- The owner's own trailers and identity.

## Where it is enforced

| Point | Mechanism |
| --- | --- |
| Local commit message | `.githooks/commit-msg` (via `core.hooksPath`) |
| Local committed files | `.githooks/pre-commit` (scans the staged diff) |
| CI | `.github/workflows/attribution-guard.yml` (push + PR: messages, PR text, added lines) |

All three load the same `guard-lib`, so local and CI can never drift. Install
the local enforcement with `bash scripts/setup.sh`.

## Rationale

The portfolio's golden rule: every platform has exactly one owner, and
ownership is expressed once, in the repository metadata — never scattered
through commit history. Tooling that rewrites history to add its own credit
gets blocked at the hook, before the commit exists.
